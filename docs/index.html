배드 스코어

배드민턴 동호인을 위한 안드로이드 점수판 앱

최신 APK 내려받기

설치 방법

  1. 위 버튼을 눌러 APK 파일을 내려받습니다.
  2. 내려받은 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 안내가 나오면 이번 설치만 허용해 주세요.
  3. 새 버전도 같은 방법으로 덮어 설치하면 되고, 기록은 그대로 남습니다.

주요 기능

  • 탭 한 번으로 점수 입력, 되돌리기, 음성 점수 안내
  • 21점 / 25점 / 31점 경기와 듀스 선택
  • 득점 그래프와 경기 시간
  • 다른 폰에 점수 공유: 같은 Wi-Fi·핫스팟, 또는 인터넷 링크

Android 7.0 이상. 이전 버전과 변경 내역
