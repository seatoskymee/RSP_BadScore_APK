# RSP BadScore (스코어 보드)

배드민턴 동호인을 위한 안드로이드 점수판 앱입니다.

## 내려받기

**[설치 안내 페이지](https://seatoskymee.github.io/RSP_BadScore_APK/)** · **[최신 APK 바로 내려받기](https://github.com/seatoskymee/RSP_BadScore_APK/releases/latest/download/RSP_BadScore.apk)**

1. 위 링크에서 APK 파일을 휴대폰으로 내려받습니다.
2. 내려받은 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 안내가 나오면 이번 설치만 허용해 주세요.
3. 새 버전이 나오면 같은 방법으로 덮어 설치하면 되고, 기록은 그대로 남습니다.

Android 7.0 이상에서 동작합니다.

## 기능

- **점수 입력**: 팀 패널을 탭하면 +1, 아래로 밀거나 `−1`을 누르면 −1, `되돌리기`로 직전 동작 취소
- **음성 안내**: 점수가 바뀔 때마다 스피커로 읽어 주고, 경기가 끝나면 승리 축하 안내
- **경기 규칙**: 새 게임마다 21점 / 25점(기본) / 31점 선택, 목표 점수가 되면 듀스 여부를 팝업으로 선택
- **복식 서브 위치**: 선수 이름과 첫 서브만 정하면, 누가 어느 쪽(좌·우) 코트에서 서브하고 받는지 점수에 맞춰 표시하고 음성으로 안내
- **코트 변경**: `⇄ 코트` 버튼으로 좌우 점수 바꾸기
- **득점 그래프**: 화면 아래에 점수 추이와 랠리별 득점/실점 표시
- **경기 시간**: 첫 점수부터 경과 시간 표시
- **화면 켜짐 유지**: 앱이 화면에 떠 있는 동안 화면이 꺼지지 않음
- **기록 저장**: 점수가 바뀔 때마다 저장되어, 앱을 다시 켜면 이어서 진행하고 예전 경기도 불러오기 가능
- **핫스팟(로컬)으로 점수 공유하기** (현재 버전에서는 잠시 꺼 둠): 같은 Wi-Fi나 핫스팟에 연결된 폰·태블릿의 브라우저로 점수판을 실시간으로 보기 (앱 설치 불필요, 여러 대 동시 가능). 핫스팟 연결용 QR과 점수판 QR을 함께 제공
- **점수 공유하기**: 링크나 QR을 받은 사람이 어디서든 브라우저로 점수판과 득점 그래프를 실시간으로 보기
- **음성 볼륨 조절**, **앱 공유하기**(설치 페이지 QR·링크 보내기)
- **업데이트 확인**: 앱을 켤 때 하루 한 번 새 버전이 있는지 확인해 알려 줌

## 참고

- 음성 안내는 휴대폰에 한국어 음성(TTS)이 설치되어 있어야 자연스럽습니다.
- "핫스팟(로컬)으로 점수 공유하기"는 같은 네트워크 안에서만 동작하며, 이때 점수는 인터넷으로 전송되지 않습니다.
- 메뉴의 "인터넷으로 점수 공유하기"는 준비 중인 기능으로, 이 버전에서는 아직 동작하지 않습니다.
- 앱 이용 현황 파악을 위해 다음 정보가 서버에 기록됩니다 (점수 공유를 켜지 않아도 기록됩니다). 이 기록은 관리자만 볼 수 있습니다.
  - 기기 모델, 안드로이드·앱 버전, 언어, 사용 시각, 앱 실행 횟수와 경기 수
  - 끝난 경기의 결과: 시각, 팀 이름, 점수, 경기 시간, 규칙
  - 경기 장소(휴대폰의 위치, 위도·경도와 동 단위 주소): 앱에서 경기 장소 기록에 "좋아요"를 누르고 위치 권한을 허용한 경우에만 기록됩니다. 기록하면 지난 경기를 장소별로 찾아볼 수 있습니다. 중단하려면 휴대폰 설정에서 이 앱의 위치 권한을 끄면 되고, 그러면 서버에 남은 최근 위치도 지워집니다.
  - 이름, 연락처는 수집하지 않습니다. 팀 이름에 실명을 넣으면 그 이름이 함께 기록되니 유의해 주세요.
- 앱에 광고가 표시됩니다 (현재는 시험용 광고).
